# 診断士ドリル

中小企業診断士試験（1次7科目・2次事例I〜IV）の問題集アプリ。
バニラHTML/CSS/JSのPWAで、オフラインでも動作します。

## 収録内容

| 区分 | 科目 | 問題数 |
|---|---|---|
| 1次 | 経済学・経済政策 | 44 |
| 1次 | 財務・会計 | 46 |
| 1次 | 企業経営理論 | 52 |
| 1次 | 運営管理 | 50 |
| 1次 | 経営法務 | 44 |
| 1次 | 経営情報システム | 44 |
| 1次 | 中小企業経営・政策 | 46 |
| 2次 | 事例I（組織・人事） | 14 |
| 2次 | 事例II（マーケ・流通） | 13 |
| 2次 | 事例III（生産・技術） | 12 |
| 2次 | 事例IV（財務・会計） | 14 |
| | **合計** | **379** |

1次は「○×一問一答」と「4肢択一」の2形式。すべての問題に解説がつきます。
2次は解答フレーム・キーワードの暗記カード（自己採点式）と、事例IVの計算問題。

## 機能

- **間隔反復（SRS）** — 正誤に応じて次回の出題日を自動調整（1日→3日→7日→…、不正解ならその日のうちに再出題）
- **苦手だけ** — 正答率60%未満、または直近で間違えた問題だけを抽出
- **模試モード** — 科目ごとに本試験と同じ問題数・制限時間で通し演習。60%／40%のラインで判定
- **おまかせ出題** — 未学習と期限超過の問題を優先して出題
- **学習記録** — 連続学習日数、16週のヒートマップ、科目別到達度、今後7日の復習予定
- **論点・形式で絞り込み** — 科目カードをタップして出題条件を設定
- **データの書き出し／読み込み** — 端末間の引き継ぎ用（JSON）

学習データはブラウザの localStorage に保存されます（サーバー送信なし）。

## 使い方

### PCで確認する

```
node server.js      # → http://localhost:8081
```

### iPhoneにインストールする（PWA）

GitHub Pages で公開したURLをSafariで開き、共有ボタン →「ホーム画面に追加」。
2回目以降はオフラインでも起動します。

## ファイル構成

```
index.html          画面の骨格（5画面 + 出題設定シート）
style.css           スタイル（ライト／ダークの両対応）
app.js              出題ロジック・SRS・統計・設定
data/*.js           科目ごとの問題データ
sw.js               Service Worker（オフラインキャッシュ）
manifest.json       PWAマニフェスト
server.js           ローカル確認用の簡易サーバー
make-icon.js        apple-touch-icon.png の生成スクリプト
```

## 問題を追加・修正する

`data/` の該当ファイルに追記するだけです。IDは科目内で一意にしてください。

```js
// ○×問題
{id:'eco045', topic:'消費者理論', type:'ox',
 q:'問題文', a:true, exp:'解説'},

// 4肢択一
{id:'eco046', topic:'消費者理論', type:'mc',
 q:'問題文', choices:['選択肢1','選択肢2','選択肢3','選択肢4'], a:0, exp:'解説'},

// 2次の暗記カード
{id:'c1k15', topic:'人事施策', type:'kw',
 q:'問い', a:'覚える内容（\\nで改行）', exp:'補足'},
```

`a` は ○×なら `true`/`false`、4択なら正解の添字（0〜3）。
選択肢はアプリ側でシャッフルされるので、正解を先頭に書いて構いません。

問題を追加したら、`sw.js` の `CACHE_NAME` の番号を上げてから公開すると更新が確実に反映されます。

## 注意

問題は一般的な学習範囲に基づく自作問題で、過去問の転載ではありません。
**中小企業経営・政策の統計数値や支援制度の要件は年度ごとに改訂される**ため、
直前期には最新の中小企業白書・施策利用ガイドブックで確認してください。
本アプリでは変動しにくい制度の枠組みを中心に収録しています。
